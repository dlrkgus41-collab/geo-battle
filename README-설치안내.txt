GEO BATTLE v1.0.0 — 관리자 전용 익명 통계 대시보드

[설치: 관리자 인증 및 보안 규칙]
1. Firebase Console → Authentication → Sign-in method에서 이메일/비밀번호 로그인 활성화.
2. Authentication → Users → Add user에서 선생님만 사용할 관리자 이메일/비밀번호 계정 생성.
3. ZIP의 rules.firestore에서 REPLACE_WITH_ADMIN_EMAIL@example.com 문자열을 관리자 이메일로 교체.
   - 이메일을 작은따옴표 안에 유지합니다. 이메일 주소는 Firebase에 생성한 계정과 정확히 같아야 합니다.
4. Firebase Console → Firestore Database → 규칙(Rules)에 수정된 rules.firestore 전체 붙여넣고 게시.
5. 이 ZIP의 index.html, admin.html, map-data.js, firebase-config.js 등 모든 파일을 Netlify 기존 사이트에 배포.
6. https://(기존-사이트-주소)/admin.html 접속 → 이메일/비밀번호로 로그인 → 오늘/7일/30일/90일 조회.

[분석 데이터]
- 전체 접속 기기·일 합계, 배틀 시작, 연습 시작, 제출 답안, 정답률
- 일별 배틀·연습 추이, 어려운 국가 TOP15, 가장 많이 혼동한 국가 쌍 TOP15, 모드별 정답률
- CSV 내보내기: 일별 수치, 국가별 오답, 국가 혼동 상위 항목
- 국가 혼동 및 모드별 상세 분석은 v1.0.0 배포 후 새 답안부터 수집됩니다.
- 익명 응답 문서에는 정답 국가/선택 국가/모드/정오/시각만 기록하고 닉네임·이메일·UID는 넣지 않습니다.
- 응답 문서 ID는 중복 기록 방지를 위해 제출 식별자를 SHA-256으로 변환합니다. 완전한 비식별성을 보장하지는 않습니다.
- 통계는 클라이언트 직접 기록 방식이므로 악의적 조작을 완전히 차단하지 못합니다.
- 관리자 계정 정보/비밀번호를 ZIP이나 학생에게 공유하지 마세요.
- 학생은 기존처럼 익명 로그인으로 게임을 이용하며 관리자 로그인은 필요 없습니다.

[참고]
- 기존 학생용 전체 통계는 공개 집계로 유지됩니다. 국가 선택 상세 응답은 관리자 계정만 읽을 수 있습니다.
- 하루 방문자 수는 브라우저 익명 계정 기준 추정치이며 기간 합산은 고유 방문자 수가 아닙니다.
- 실제 Firebase 운영 환경 통합 테스트는 배포 후 필요합니다.


v1.0.2 변경사항
- 온라인 배틀 종료 시 최종 순위 아래 복습 노트 자동 표시
- 쉬움: 같은 권역 정답만, 보통: 권역 혼합, 어려움: 인접 국가 중심 선지
- 전 세계 문제 후보 전체 지도 데이터로 확대, 문제마다 무작위 섞기
- 접속 기기 집계: 브라우저 로컬 저장소의 지속 식별자로 날짜별 1회만 기록
- 오늘 접속 기기 수는 새로운 visitorsV2 집계로 0부터 다시 시작. 과거 수치는 삭제하지 않음
- Firestore 규칙에 visitorsV2 필드 추가: 반드시 Firebase Console에서 새 규칙 게시
- 동일 기기라도 브라우저/프로필/시크릿 모드가 다르거나 저장소 삭제 시 별도 집계될 수 있음
- GitHub Pages: index.html, admin.html, rules.firestore(규칙은 Firebase Console에만 게시)
